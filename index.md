# OpenChessClub Documentation
{: .fs-9 }

Welcome to the documentation portal of **OpenChessClub**.
{: .fs-6 .fw-300 }

[Get started now](/docs/getting-started){: .btn .btn-primary .fs-5 .mb-4 .mb-md-0 .mr-2 }
[View it on GitHub][OpenChessClub Repo]{: .btn .fs-5 .mb-4 .mb-md-0 }

---

**OpenChessClub** is a free and open-source platform for managing chess clubs, players, and tournaments. Built for small and large chess clubs alike. Many new features are to be added in the coming weeks. 

Browse the docs to learn more about how to set up OpenChessClub.

## Contributing to the documentation

The source code for the documentation portal is found in the GitHub repository. If you wish to add pages or make changes, please feel free to submit a pull request! All changes are welcome :)


### Contributing

When contributing to this repository, please first discuss the change you wish to make via issue,
email, or any other method with the owners of this repository before making a change. Read more about becoming a contributor in [our GitHub repo](https://github.com/OpenChessClub/openchessclub).
